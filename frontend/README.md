# SALFORD — React Native CLI

تطبيق أصلي باستخدام React Native 0.87.1 وTypeScript، بدون Expo أو WebView.

## التقسيم

- `src/App.tsx`: بوابة الدور من جلسة السيرفر، وشاشات Figma الأصلية للدخول والدفع ومعرض التصميم.
- `src/admin/`: نظرة عامة، تحرير ونشر وأرشفة الدورات والفصول والدروس، إدارة الطلاب، تعديل الخطط، محتوى ورفع صور وفيديو، سجل الدفع للعرض، وسجل النشاط.
- `src/learning/`: بيانات الطالب من السيرفر: الرئيسية والبحث والدورات والمحفوظات والتاريخ والملف والإعدادات والشهادات والإشعارات والتشغيل.
- `src/services/api.ts`: الاتصال، تحديث جلسة واحد مشترك، منع إحياء جلسة خرج منها المستخدم، وتحويل روابط localhost للمحاكي.
- `src/components/`: عناصر الموبايل المشتركة ورسم Figma ونموذج الدفع.
- `src/state/`: بيانات العرض المحلي معزولة عن الحسابات. لا كلمات مرور أو بطاقات أو tokens في AsyncStorage.
- `src/design/` و`src/assets/`: التصميم والأصول الأصلية.
- `__tests__/`: تدفقات الموبايل، الجلسات، الدفع وتسلسل أحداث الفيديو.

## الإدارة على الموبايل

سجّل الدخول بحساب أدمن من السيرفر نفسه. حسابات التطوير المحلية في `../backendCSC/.local/local-app/demo-accounts.json`؛ لا تنشر الملف.
حساب الطالب لا يرى الإدارة، وتتحقق API من الدور أيضًا. إعداد مفتاح بوابة الإدارة اختياري داخل لوحة الموبايل للإنتاج ولا يُحفظ على القرص.
الإدارة لا تحتوي شاشة دفع؛ تعرض العمليات الوهمية التي أنشأها الطالب فقط.

## الدفع

من Profile → Subscription plans. عاد نموذج Figma الذي يحتوي البطاقة والاسم والتاريخ وCVV. اضغط **Fill test payment details**.
الرقم الوحيد المقبول `4242 4242 4242 4242` وCVV `123` مع تاريخ مستقبلي.
PayPal وGoogle Pay غير متصلين. لا توجد أي عملية مالية حقيقية، ولا يُرسل أي حقل بطاقة للسيرفر. يُرسل planId فقط مع مفتاح يمنع التكرار.
فشل الشبكة لا يفتح شاشة النجاح.
إذا لزم تسجيل الدخول أثناء الدفع، تعود الخطة المختارة بعد الدخول الحقيقي. البريد غير الموثّق يعرض زر Resend verification email. Google login غير المهيأ لا يفتح معاينة حساب ولا يمنح جلسة وهمية.

قاعدة الباك إند الحالية محلية عبر PGlite؛ الموبايل لا يحمل أسرارًا أو مفاتيح Supabase. [إعداد الاتصال والفحص المحلي](../docs/local-run.md).

## التعلّم

النشر من الأدمن يظهر في كتالوج الطالب بعد التحديث. تسجيل الدورة وصلاحية الاشتراك من السيرفر. تُستخدم نسخة المنهج المرتبطة بتسجيل الطالب عند الاستكمال.
التقدم يعتمد على أحداث مشاهدة متسلسلة يتحقق منها السيرفر، ولا يتحول seek أو onEnd إلى نسبة 100 محليًا. الشهادة تظهر فقط من API بعد استحقاقها ومعالجتها.
ينتهي رابط الفيديو المؤقت بعد خمس دقائق؛ زر متابعة الدرس يفتح جلسة جديدة ويستأنف من الموضع المحفوظ.

## التشغيل

**Windows، الطريقة اليومية الموصى بها:** من `C:\Projects\CSCApp` نفّذ `npm run android:dev`، أو نفس الأمر من مجلد frontend. يختار Pixel8 الموجود وJDK17، ويتحقق من Metro8082 ويضبط reverse ويفتح Debug. لا يعيد البناء للتغييرات العادية في TS/TSX/JS/JSX؛ احفظ الملف لاستخدام Fast Refresh. يبني عند تغييرات Native فقط أو بوجود `--rebuild`. لإيقاف Metro الخاص بالمشروع: `npm run android:dev -- --stop`. لا يشغّل backend أو يغير قاعدة البيانات.

السجلات في `artifacts/android-dev`؛ [التفاصيل والتشخيص](../docs/android-dev.md). الأوامر اليدوية التالية بديل، ولا تُشغّلها فوق نسخة Metro التي فتحها المشغّل.

من `C:\Projects\CSCApp\frontend`: ثبّت بـ`npm ci` عند الحاجة، ثم `npm start` في Terminal و`npm run android -- --active-arch-only --no-packager` في Terminal آخر، بعد تشغيل backend وفتح محاكي Android. أوامر الجذر المكافئة موضحة في [README](../README.md). للإيقاف `Ctrl+C`؛ أمر تثبيت Android ينتهي تلقائيًا.

المحاكي Android يستخدم `http://10.0.2.2:3000`، وiOS المحلي `http://127.0.0.1:3000`. المنافذ العامة من `src/services/local-config.json` وتقرأها `api.ts` وأوامر CLI وMetro والباك إند ولوحة الكمبيوتر. لا تضع أي سر في هذا الملف. إعداد هاتف USB الحقيقي منفصل في دليل التشغيل؛ لا نفتح السيرفر على الشبكة الخارجية.
Metro المحلي وأوامر بناء الموبايل تستخدم البورت **8082**. الباك إند يبقى على **3000**؛ لا تخلط البورتين. [التشغيل المحلي فقط](../docs/local-run.md).
إضافة مكتبات `@react-native-documents/picker` و`react-native-blob-util` تحتاج بناء Native جديد. على Mac شغّل `pod install` داخل ios.

البريد المحلي يُحفظ في مجلد السيرفر `.local/local-app/mail`، وليس بريدًا خارجيًا. Google/Apple login يتطلبان إعداد مزودي الهوية، ولا يتم تزوير جلسة اجتماعية. الجلسات لا تستمر بعد إغلاق عملية التطبيق؛ يلزم الدخول مجددًا.
