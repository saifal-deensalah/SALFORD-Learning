# SALFORD — تصميم الباك إند

**الحالة: تحليل وتصميم قابل للتنفيذ، وليس سيرفرًا شغالًا أو ربطًا منفذًا.** أُعدّ بتاريخ 27 أغسطس 2026 بعد قراءة فرونت إند المشروع، الشاشات الـ18، اللوحات الإضافية، التخزين المحلي والاختبارات. لم تتغير شاشة أو وظيفة في تطبيق الموبايل خلال هذه المهمة.

**مرجع تصميم فقط:** نُفّذ السيرفر لاحقًا في المجلد المستقل [backendCSC](../../backendCSC/README.md). نُقل هذا المرجع إلى `docs/backend` حتى لا يختلط مع التنفيذ. ملفات `src/...` المذكورة في التحليل تعني ملفات تطبيق [frontend](../../frontend/README.md). عقد التنفيذ الحالي في `backendCSC/contracts/openapi.json`؛ لا تشغّل SQL المرجعي على قاعدة السيرفر الحالية.

## الاختيار المقترح

**NestJS + TypeScript + PostgreSQL** كسيرفر واحد مقسم حسب الوظيفة. طبقة repositories تستخدم `pg` واستعلامات parameterized مع migrations SQL. لا حاجة إلى ORM إلزامي أو microservices لهذا الحجم؛ يمكن اعتماد ORM لاحقًا بشرط الاحتفاظ بنفس القيود والـtransactions. **Redis + BullMQ** للمهام الخلفية، وتخزين ملفات خاص متوافق مع S3 مع CDN للفيديو والصور والشهادات.

الخدمات الخارجية اللازمة: بريد إرسال، Google/Apple Sign-In، Apple/Google billing عند النشر على المتاجر، FCM/APNs، وتخزين/بث المحتوى. لا تُنشأ حسابات أو خدمات مدفوعة تلقائيًا بهذا التصميم.

## قرارات لا يمكن استنتاجها من Figma

1. سعر كل خطة، ما الدورات المشمولة فيها، ومدة التجديد. أسعار `$250` و`$9.99` الموجودة في الواجهة أمثلة، وليست مواصفات تجارية معتمدة.
2. بلد تسجيل النشاط التجاري، بلدان التوزيع، وطريقة نشر التطبيق؛ هذه تحدد قنوات الدفع المتاحة وشروط المتاجر.
3. هل الدورات تباع منفردة أم ضمن اشتراك؟ **افتراض النسخة الأولى: اشتراكات + دورات مجانية فقط**. شراء دورة منفردة يحتاج توسعة طلبات وحقوق وصول، وغير مضمن في هذا العقد.
4. الفيديوهات الحقيقية وحقوق استخدامها، سياسة الشهادات، وهل يوجد اعتماد خارجي. لا يفترض التصميم وجود اعتماد.
5. هل الجمهور أطفال؟ الرسم وحده ليس دليلًا؛ يجب حسم الفئة العمرية وسياسة الخصوصية قبل الإنتاج.

ميزة Offline Access المكتوبة داخل Figma ليست موجودة في مشغّل التطبيق الحالي. **تنزيل فيديو محمي ومزامنة تقدم دون إنترنت خارج نطاق v1**؛ يجب إخفاء الوعد من الخطط إلى أن يُنفذ ترخيص تنزيل وانتهاء صلاحية وضوابط تقدم مناسبة.

## التحقق المحلي من التصميم

هذه أوامر تحقق، وليست أوامر تشغيل API:

```powershell
cd C:\Projects\CSCApp\docs\backend\design-tools
npm ci
npm run generate
npm run validate
```

يُختبر SQL في PostgreSQL مدمج مؤقت عبر PGlite ولا يتم الاتصال بأي قاعدة إنتاج. لم يُنشأ `main.ts` أو HTTP server؛ تنفيذ الوحدات والربط مرحلة لاحقة. لا تستخدم عنوان `api.example.com` الموجود بالعقد كخدمة فعلية.
