# SALFORD Admin — لوحة الكمبيوتر المحلية

لوحة React/Vite اختيارية تستخدم `backendCSC` ونفس حساب وصلاحيات الأدمن على الموبايل. روجع المجلد الحالي وأُعيدت أوامر تشغيله ضمن المراجعة المحلية؛ لم تُضف بوابة دفع جديدة ولم تُنقل الإدارة من الموبايل.

## التشغيل

من `C:\Projects\CSCApp` شغّل backend وفق [README الرئيسي](../README.md)، ثم في Terminal منفصل:

```powershell
cd C:\Projects\CSCApp
npm run start:admin
```

افتح [اللوحة](http://127.0.0.1:5173/admin/). Vite مربوط بالكمبيوتر فقط؛ الطلبات `/v1` تمر إلى backend على3000. المنافذ من `../frontend/src/services/local-config.json`. `npm run build:admin` يبني الملفات فقط. **backend لا يخدم `/admin/` على3000.** للإيقاف `Ctrl+C`.

من داخل `admin-dashboard` تتوفر `npm run dev` و`npm run typecheck` و`npm run build`. لا يوجد script lint/test منفصل؛ اختبار عميل الجلسات ضمن اختبارات backend.

## الصلاحيات

استخدم حسابًا حقيقيًا دوره `admin`، وليس حساب طالب. الملف الخاص `backendCSC/.local/local-app/demo-accounts.json` قد يحتوي حسابات التطوير الحالية؛ لا تنشره ولا تنشئ حسابات جديدة في Supabase لمجرد الفحص. اختبار كامل آمن بحسابات fixture موضح في [البيئة المعزولة](../docs/local-run.md).

NestJS يفرض الدور على كل عملية إدارة. في وضع development/test المحلي، جلسة admin مطلوبة ولا يحتاج مفتاح بوابة إضافيًا. حماية `ADMIN_API_ENABLED` و`X-Admin-Key` تخص وضع production وتبقى دون تجاوز؛ لا تغيّر وضع التشغيل للتحايل عليها. التوكن ومفتاح البوابة في الذاكرة فقط؛ إعادة تحميل الصفحة تتطلب الدخول مجددًا. لا يوجد حفظ في localStorage.

## الوظائف

- الإحصائيات، تحرير مسودات الدورات والفصول والدروس ثم النشر/الأرشفة.
- بحث الطلاب وإيقاف/تفعيل حساباتهم، مع حماية حسابات الأدمن.
- تعديل الخطط والأسعار التجريبية والتغطية ضمن قيود الاشتراكات الفعالة.
- سجل الدفعات **للعرض فقط**؛ الدفع الوهمي مكانه الموبايل.
- التصنيفات والمدرسون، رفع صور حتى5MB وفيديو حتى100MB ومعرفة حالة المعالجة، وسجل نشاط الأدمن.

`src/api.ts` للطلبات والجلسات والرفع، `src/ui.tsx` للحالات والقوائم والصفحات، `src/pages` للميزات، و`src/styles.css` للتنسيق. بيانات الطالب المتصل بالموبايل من السيرفر؛ معرض Figma المحلي منفصل. [نتائج الاختبار وحدوده](../docs/final-local-review.md).
